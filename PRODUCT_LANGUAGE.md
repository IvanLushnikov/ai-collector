# Словарь пользовательской терминологии AI Collector

Документ фиксирует, как называть сущности продукта в интерфейсе для русскоязычных пользователей (МФО, банки, ПКО, операторы взыскания).

Внутренние имена в коде и API могут отличаться. Не переименовывайте код ради UX — используйте этот словарь при написании текстов.

## Продукт

| Внутренний термин | Пользовательский термин | Не использовать | Комментарий |
|---|---|---|---|
| AI Collector | ИИ-коллектор | AI-коллектор, AI Collector | Единое имя в личном кабинете (`prototype.html`) |
| MVP Lab | (не показывать) | MVP, lab | Только внутренняя и инвесторская документация |
| decision dashboard | продуктовый дашборд | decision workspace | Только `index.html`, не для операторов |

## Известные расхождения (требуют продуктового решения)

| Где | Сейчас | Рекомендация | Статус |
|---|---|---|---|
| `index.html` vs `prototype.html` | AI-коллектор vs ИИ-коллектор | ИИ-коллектор в пользовательском кабинете | зафиксировано, не меняли |
| `index.html` навигация | Overview, CJM, Compliance | допустимо для decision dashboard | не пользовательский кабинет |
| Backend import errors (`src/import/*`) | русские сообщения с next step | код ошибки API остаётся английским | исправлено в T-214 |
| API errors (`VALIDATION_ERROR`, …) | код на английском | код для API + русский `message` для UI | по мере появления UI-слоя |

## Быстрые замены при ревью copy

- «Submit» → «Сохранить» / «Отправить» / конкретное действие  
- «Deploy» → «Опубликовать» / «Запустить кампанию»  
- «Validation error» → «Не удалось … Проверьте …»  
- «Вы уверены?» → «Кампания остановится. Новые звонки не начнутся.»  
- «OK» → «Понятно» / «Закрыть» / конкретное действие  

Обновляйте таблицу, когда в продукте появляется новая сущность или меняется устоявшийся термин.
