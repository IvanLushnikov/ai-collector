Политика конфиденциальности

Какие данные обрабатываются

Платформа ИИ-коллектор обрабатывает данные в двух контурах:

Кабинет (после регистрации): имя, email, название организации, сведения кампаний и загруженной базы должников. Данные нужны для создания аккаунта, управления кампаниями и ведения журнала решений.

Форма заявки (до регистрации): название организации, имя, email, роль, сегмент и краткое описание запроса. Данные передаются через защищённый канал для обработки входящего обращения. Telegram Bot API и GitHub Actions используются как транзитная среда для уведомления команды; хранения данных в этих сервисах не предполагается.

Зачем используются данные

Данные кабинета — для предоставления функций продукта в рамках аккаунта организации. Данные формы заявки — для ответа на обращение и согласования формата пилота или демо.

Доступ и хранение

Доступ к данным кабинета ограничен сотрудниками организации согласно ролям. Пароль хранится только в виде хеша. Данные заявки передаются в Telegram-чат команды для обработки обращения.

Права субъекта

Вы вправе запросить уточнение, удаление или ограничение обработки данных. Для этого обратитесь к нам напрямую.

Этот текст описывает текущий тестовый контур продукта. Коммерческий договор, DPA и юридически значимые формулировки оформляются отдельно перед production-запуском.
