## 2. Карточки примеров

### RU-1. НОТА МОДУС Взыскание
**URL:** https://nota.tech/products/modus/collection

**Что сильно**
- **Hero:** продукт назван предметно («Взыскание»), подзаголовок про автоматизацию BPM для крупных компаний; CTA «Получить демо».
- **Структура:** этапы Pre → Soft → Hard → Legal → Исполнительное; каждая стадия — отдельный блок с одной задачей.
- **CTA:** повторяющийся «Получить демо» + финальная форма (имя, компания, должность, телефон, email).
- **Trust:** реестр российского ПО; «15 лет опыта»; топ-банки; отраслевое законодательство.
- **Visual:** корпоративный холдинговый тон Т1, без purple-glow.

**Взять (3–5)**
1. Стадии процесса как скелет страницы (не фичи-список).
2. Trust через реестр ПО / срок на рынке / отраслевой закон — без «ИИ всё решит».
3. Единый CTA на демо во всех блоках.
4. «Для кого» через этапы и роли (оператор КЦ, выезд, legal), не через абстрактные персоны.
5. Форма заявки с должностью — сигнал enterprise-квалификации лида.

**Не брать**
1. Перегруз повторными «Получить демо» внутри каждого микроблока без паузы для чтения.
2. Видео/дашборд как замена value proposition (если не объясняет пилот за 5 сек).

**К нашим блокам:** Hero · Как это работает · Trust · Для кого · Модалка заявки.

### RU-2. FIS Collection
**URL:** https://fisgroup.ru/products/collection/

**Что сильно**
- **Hero:** сразу цифры кейсов (рост взысканий / производительности) рядом с названием системы.
- **Структура:** кейсы → «что получите» → стадии взыскания → возможности → форма.
- **CTA:** «Получить презентацию» / «Получить консультацию» / демо платформы.
- **Trust:** конкретные операционные метрики (портфель договоров, время ожидания, конверсия урегулирования).
- **Visual:** продуктовый B2B, реестр ПО, без «нейросетевого» декора.

**Взять**
1. Метрики кейсов как доказательство, не как hero-стат-лента ради красоты.
2. Явная карта стадий Pre/Soft/Hard/Legal — язык рынка коллекшн.
3. «Готовое решение / срок запуска» как ответ на страх долгого внедрения.
4. Форма с именем, email, телефоном, компанией — близко к нашей модалке.

**Не брать**
1. Обещания вроде «возврат 97%» без контекста сегмента — у нас нельзя обещать автономное взыскание.
2. Смешение «демо платформы» и «консультации» как двух равноправных главных CTA.

**К нашим блокам:** Hero (доказательство) · Trust · Как это работает · Финальный CTA.

**Не брать**
1. Длинные «простыни» текста без сканируемых подзаголовков (для нашего лендинга — короче).

### RU-6. Скорозвон — предиктивный обзвон
**URL:** https://skorozvon.ru/solutions/predictive

**Что сильно**
- **Hero:** ясный VP за 5 сек («обзванивайте базы в 3 раза быстрее») + 3 буллета.
- **Структура:** определение → как работает → зачем → таблица сравнения → кейсы.
- **CTA:** один главный вход (триал/консультация), без конкуренции второстепенных офферов в hero.
- **Trust:** кейсы МФО/HR/юруслуг с «было → сделали → стало».
- **Visual:** чистый SaaS, но не purple-AI; понятные цифры.

**Взять**
1. Определение термина человеческим языком (что такое dialer / почему это нужно).

3. Кейсы в формате до/после, а не логотипы без смысла.
4. Одна секция = одна задача.

**Не брать**
1. Consumer-тон «зарабатывайте больше» — для банков/ПКО смягчить до «повышаете контактность / контролируете нагрузку».
2. Self-serve «попробовать бесплатно» как главный CTA (у нас демо-модель).

3. «Всё для КЦ в одном месте» → у нас аналог «проверки + диалог + эскалация + журнал».

**Не брать**
1. Слишком широкий CX-scope (наш лендинг уже пилота взыскания).
2. AI-first формулировки без операционного якоря.

**К нашим блокам:** CTA/demo funnel · Narrative pacing · Для кого (enterprise).

## 3. Сводка паттернов

### Hero
- Называть **процесс и результат контроля**, не технологию: «управляемое телефонное взыскание», «scale & control», «взыскание на этапах soft→legal».
- За 5 секунд: *кому* (банки/МФО/ПКО) + *что делает* + *чем не является* (не автономный бот).
- Один главный CTA. Вторичные (ROI, brief, презентация) — ниже или в тексте.
- Первый экран без дашборда-коллажа и без pill-кластеров фич.

### Narrative / структура
- Скелет страницы = **операционный процесс** (стадии / 4–7 шагов), не каталог модулей.
- Одна секция — одна задача: боли → как работает → trust → для кого → демо.
- Before/After или «без / с» работает лучше, чем абстрактные «преимущества».
- Пилотный язык: срок, контур, эскалация человеку.

### CTA / форма
- Sales-led: «Назначить демо» / «Получить демо» / «Talk to an Expert».
- Поля: имя, компания, email, телефон (± должность для квалификации).
- Усиление конверсии: блок «что будет на демо» (сценарий, журнал, проверки, эскалация).
- Sticky CTA допустим, если не конкурирует с другими кнопками и не перекрывает контент.

### Trust
- Регуляторика и процедуры > прилагательные: реестр ПО, журнал, роли, проверки до звонка, compliance.
- Именованные кейсы / сегменты / стаж рынка.
- Формула **автоматизация рутины + человек на спорах**.
- Без истерики («штрафы», «катастрофа») и без «AI magic».

### Визуальный язык
- Brand/product recognisable: корпоративный fintech/ops, светлая или нейтральная схема, реальные схемы процесса.
- Избегать: purple/indigo glow, glass, emoji, floating badges, Midjourney-абстракции.
- Движение — для иерархии (появление шагов, sticky), не для «нейро-вау».
- Карточки — только если несут взаимодействие или сравнение; не украшать hero карточками.

### Русский B2B-copy
- Естественные глаголы: «назначаем», «проверяем», «передаём специалисту», «фиксируем в журнале».
- Отраслевой словарь: просрочка, кампания, дозвон, эскалация, пилот — вместо campaign/agentic/LLM.
- Короткие абзацы как у Контура: одна мысль — один блок.
- Не калькировать «Recover the payment. Keep the customer.» дословно — переносить смысл: «возвращаем контакт и платёжную дисциплину, не ломая процесс контроля».

## 4. Рекомендации для нашего лендинга

### Топ-10: проблема AI-лендинга → рыночный паттерн → как применить → эффект

| # | Проблема AI-лендинга | Рыночный паттерн | Как применить у нас | Эффект |
|---|----------------------|------------------|---------------------|--------|
| 1 | Hero про «магический голосовой ИИ» | HighRadius / НОТА: control + предмет «взыскание» | Заголовок: управляемая автоматизация телефонного взыскания с проверками и эскалацией; подзаголовок отрицает полную автономию | ЛПР за 5 сек понимает пилот, не бота |
| 2 | Несколько CTA (триал, ROI, «поговорить с ИИ») | Genesys / НОТА: один demo CTA | Везде только «Назначить демо»; sticky = тот же CTA | Рост кликов в форму, меньше рассеивания |
| 3 | Фичи-облако в hero | Скорозвон / Symend: 3 буллета или 1 outcome | Hero: бренд + 1 headline + 1 фраза + CTA + максимум 3 тезиса (проверки / специалист / журнал) | Снижение когнитивной нагрузки |
| 4 | Нет «как работает» | IQDialer 4 шага / Symend 5 steps / наш 7-step design | Секция шагов человеческим языком: сценарий → проверки → контакт → диалог → спорное → специалист → журнал | Доверие к управляемости |
| 5 | Trust = «SOC + нейросеть» без смысла | TrueAccord compliance / Диадок процедурность / Infinity закон | Trust-блок: ограничения до звонка, журнал действий, передача человеку, контур пилота | Снятие страха регуляторики |
| 6 | Пустые метрики «+300% AI» | FIS / Скорозвон: метрики в контексте кейса | Если цифры — только с оговоркой пилота/сегмента; иначе качественные доказательства процесса | Достоверность, меньше недоверия |
| 7 | «Для всех» без сегментов | LuxBase / MightyCall «кому подойдёт» | Блок: банки / МФО / ПКО / КЦ взыскания — по одной фразе сценария | Квалификация лида |
| 8 | Форма без ожиданий | Catchpole demo «what you’ll see» | В модалке или рядом: «На демо покажем проверки, эскалацию и журнал» | Выше completion и качество лида |
| 9 | Визуал purple-glow / glass | Диадок / Naumen / Infinity: нейтральный enterprise | CSS-переменные fintech-ops; схема процесса или спокойный product visual; без glow | Отстройка от AI-startup vibe |
| 10 | Обещание «заменим коллекторов» | Symend keep customer / HighRadius human when needed / Infinity «робот на рутину» | Copy: автоматизация рутинных контактов + специалист на споры; CTA «Назначить демо» пилота | Соответствие реальному продукту и compliance |

### Anti-patterns нейросетевого AI-лендинга (не делать)

1. Purple/indigo градиенты, glow, glassmorphism, «орбы», particle backgrounds.
2. Hero-коллаж из фейковых дашбордов и чатов бота.
3. Pill-clusters: «GPT · Voice · Realtime · Agentic».
4. Emoji в заголовках и trust-бейджах.
5. Value prop «ИИ, который сам взыщет долги».
6. Два равноправных CTA в первом экране.
7. Стат-лента без источника и без привязки к пилоту.
8. Англицизмы там, где есть точный русский термин (campaign, agentic, human-in-the-loop как единственная формулировка).
9. Dribbble-only концепты без реального продукта.
10. Consumer fintech эстетика (ярко, игриво, «приложение в кармане»).

## 5. Метод

### Где искал
- Прямой поиск по сегментам: «автоматизация взыскания», FIS / НОТА / LuxBase / МФС, dialer (Скорозвон, IQDialer, Infinity, MightyCall), КЦ банков (Naumen, ЦРТ).
- Trust-heavy соседние B2B: Контур.Диадок (regulated ops + русский copy).
- International: enterprise collections (HighRadius, Symend, TrueAccord, Catchpole), enterprise CC (Genesys).
- Проверка живых URL через fetch страниц (контент hero/CTA/секций), не по каталогам картинок.

### Как отсекал
- **Отсечено:** consumer-банки/приложения; кабинеты/admin UI как «лендинг»; чистые AI-startup лендинги с glow и «магией»; Dribbble без продукта; страницы только с прайсом без narrative.
- **Допущено соседнее:** dialer и ЭДО — если переносятся структура, demo-CTA и trust-тон.
- **Снижена полезность:** сайты со слабым CTA (LuxBase), с AI-шумом в copy (частично Catchpole), с устаревшей вёрсткой (ЦРТ) — паттерны всё равно извлечены.
- **Не выдумано:** в shortlist только проверенные URL с доступным контентом на дату исследования.
