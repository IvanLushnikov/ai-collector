Варианты телефонии для ИИ-коллектора

Сравнение каналов исходящего звонка: что клиент вставляет в кабинет, плюсы, минусы, сложность для текущего репозитория. Live без legal memo по автовызовам и без маркировки не запускается ни в одном варианте.

Рекомендация на пилот

Платформенный МТС Exolve Voice API: мы звоним, клиент даёт только направление перевода. «Принеси любую SIP» — отдельный этап после пилота, через SIP-шлюз в РФ (LiveKit SIP), не через OpenAI и не через голосового робота оператора.

Ключ API и SIP host/pass — не «или»

У Манго API управляет звонком, SIP несёт голос. Одного ключа недостаточно для нашего сценария; одного host/pass недостаточно для перевода, CDR и записи. Универсальный SIP в форме кабинета = один шлюз, не отдельный адаптер на каждого оператора.

Как читать сложность

Низкая

HTTP-адаптер или чужой робот. Мало своего медиакода. Не значит, что можно в live.

Средняя

Voice API + секреты + probe маркировки, записи и перевода. Совпадает с уже заложенным VoiceProviderAdapter.

Высокая

SIP user agent или LiveKit: RTP, NAT, REFER, своя запись. Это мост, не полноценная АТС.
