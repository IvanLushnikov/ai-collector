# Async side-effect SoT (Controlled Pilot)

Дата: 21.08.2026  
Статус: рабочее правило выравнивания; не заменяет ADR 0001

## Решение

1. **Transactional Outbox** (`OutboxEvent` + `src/integrations/outbox.ts`) — канонический async SoT для внешних side effects, связанных с domain mutations (campaign create/status и дальнейшие wire-ups в `T-258`).
2. **BullMQ / `src/jobs/*`** — platform skeleton (health ping, optional sandbox enqueue flag). Не второй оркестратор и не место для новой бизнес-логики dial/compliance, пока нет live HTTP provider path.
3. Sandbox dial по умолчанию остаётся **синхронным** HTTP path через compliance engine; очередь не подменяет fail-closed pre-dial.

## Не делать

- Не вводить третью очередь/брокер «для порядка».
- Не считать job worker доказательством live orchestration.
- Не удалять BullMQ из стека без ADR: он остаётся platform dependency из ADR 0001.
